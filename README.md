# Restaurant Management System

A full-stack Web-Based Application Development project.

## Milestone 3: Backend Implementation
The backend API is fully implemented with Node.js, Express, PostgreSQL, and Prisma. It includes JWT-based authentication, Role-Based Access Control (RBAC), and automated testing.

## Workflows Implemented
1. **Table Reservation & Pre-Order:** Customer table booking with optional pre-ordered meals and automatic total calculation.
2. **Online Ordering:** Delivery and Takeaway cart system with Admin status tracking.
3. **Catering & Event Booking:** Large-scale event booking with price-per-head logic and Admin approval pipeline.
